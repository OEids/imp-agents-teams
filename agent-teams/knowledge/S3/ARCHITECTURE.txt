## Data Flow: Before vs After

### BEFORE (Manual Process)
```
Customer Data (Wrong Format)
        │
        ├─ Manual inspection
        ├─ Check column names
        ├─ Retype/copy-paste
        ├─ Find correct import file
        ├─ Manual mapping
        ├─ Error checking
        ├─ Merge with existing
        └─ Risk of errors ✗

Time: 30-60 minutes per import
Risk: High (human error)
```

### AFTER (Automated Process)
```
Customer Data (Any Format)
        │
        ├─ Automatic detection
        ├─ Intelligent analysis
        ├─ Auto column mapping
        ├─ Find import file
        ├─ Automated merge
        ├─ Built-in validation
        └─ Status report ✓

Time: < 1 minute per import
Risk: Low (validated)
```

## Agent Processing Pipeline

### For Each Incoming File:

```
┌─────────────────────────────────────────┐
│ STEP 1: LOAD & ANALYZE                  │
├─────────────────────────────────────────┤
│ ├─ Read CSV/Excel file                  │
│ ├─ Extract column headers                │
│ ├─ Count rows                            │
│ └─ Check for data quality issues         │
└───────────────┬─────────────────────────┘
                │
┌───────────────▼─────────────────────────┐
│ STEP 2: FORMAT DETECTION                │
├─────────────────────────────────────────┤
│ ├─ Compare to known CSV schemas         │
│ ├─ Check for exact match                │
│ ├─ Check for partial match              │
│ ├─ Analyze column keywords              │
│ └─ Determine data type                  │
└───────────────┬─────────────────────────┘
                │
        ┌───────▼────────┐
        │ Template?      │
        │ (Already OK)   │
        └───────┬────────┘
       Yes│     │No
          │     ↓
          │  ┌────────────────────────────┐
          │  │ STEP 3: MAP COLUMNS        │
          │  ├────────────────────────────┤
          │  │ ├─ Exact match mapping     │
          │  │ ├─ Fuzzy match (similar)   │
          │  │ ├─ Infer missing columns   │
          │  │ ├─ Apply defaults          │
          │  │ └─ Create mapped dataframe │
          │  └────────────┬───────────────┘
          │               │
          │  ┌────────────▼───────────────┐
          │  │ STEP 4: LOAD EXISTING CSV  │
          │  ├────────────────────────────┤
          │  │ ├─ Read current import CSV │
          │  │ ├─ Parse existing data     │
          │  │ └─ Check structure         │
          │  └────────────┬───────────────┘
          │               │
          │  ┌────────────▼───────────────┐
          │  │ STEP 5: MERGE DATA         │
          │  ├────────────────────────────┤
          │  │ ├─ Concatenate dataframes  │
          │  │ ├─ Remove duplicates       │
          │  │ ├─ Keep latest version     │
          │  │ └─ Validate merged data    │
          │  └────────────┬───────────────┘
          │               │
          │  ┌────────────▼───────────────┐
          │  │ STEP 6: WRITE UPDATED CSV  │
          │  ├────────────────────────────┤
          │  │ ├─ Export to CSV format    │
          │  │ ├─ Save to import folder   │
          │  │ └─ Verify file created     │
          │  └────────────┬───────────────┘
          │               │
          └───────┬───────┘
                  │
        ┌─────────▼──────────────┐
        │ ✓ IMPORT COMPLETE      │
        │ Return Status:         │
        │ • Success: true        │
        │ • Rows processed: N    │
        │ • File: [CSV name]     │
        │ • Errors: [if any]     │
        └────────────────────────┘
```

## Error Handling Flow

```
Incoming Data
     │
     ↓
Try to Process
     │
    ┌┴─────────────────────────┐
    │                          │
Success             Error Detected
    │                          │
    ├─ Save to CSV            ├─ Identify Error
    ├─ Merge with Existing     ├─ Generate Error Message
    ├─ Return Status: True     ├─ Suggest Fix
    │                          ├─ Return Status: False
    │                          │
    └─────────┬────────────────┘
              │
              ↓
        ┌──────────────┐
        │ Return Dict: │
        │ success: T/F │
        │ errors: [...] 
        │ rows_proc: N │
        └──────────────┘
```
